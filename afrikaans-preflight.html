Afrikaans Preflight

Conservative mechanical cleanup for Afrikaans DOCX files before substantive editing. Preflight corrects only defined punctuation and quotation patterns; it flags uncertain cases instead of guessing.

Run Preflight

Your original file is never overwritten. You will receive a new cleaned DOCX and a short report.

Use the protected-access code supplied by ClearCopy Clinic.
DOCX only, maximum 8 MB.

What v1 checks

  • Incorrect forms of ’n.
  • Obvious numeric apostrophe forms such as 1950's → 1950’s.
  • Clear straight quotation-mark pairs.
  • Single-quoted primary passages and nested quotations where the pattern is unambiguous.
  • Ambiguous quotation patterns are left unchanged and flagged for review.

It does not check grammar, translation quality, facts, meaning, terminology or full house style.
