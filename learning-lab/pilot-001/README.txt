CCC LEARNING LAB — WEB PILOT 001

CONTENTS
- index.html: 5-question, instant-feedback mobile warm-up
- diagnostic.html: optional longer 20-question self-report diagnostic (unmarked)

TRY IT FIRST
- Double-click index.html to open in Chrome or Edge.
- Take the short quiz and check that all five questions advance.
- The full diagnostic link works because diagnostic.html is in the same folder.

HOST ON THE EXISTING CCC GITHUB PAGES SITE
- Use the CCC website source checkout on your PC, not OneDrive.
- Place index.html and diagnostic.html directly in learning-lab/pilot-001/.
- Preview by serving the repository root with a local static HTTP server.
- Do not add the pilot to the public CCC navigation.
- The GitHub Pages address is https://clearcopy.clinic/learning-lab/pilot-001/.
- Firebase remains separate and is not required by these pages.

ACCESS AND PRIVACY
- This version has NO authentication. An unpublished/unlinked URL plus noindex is NOT private.
- It asks for no name or contact details and does not submit quiz answers to a server.
- The optional long diagnostic temporarily stores answers in that browser's local storage,
  and can export them only after the user intentionally clicks Export.
- For actual protected learner accounts, server-stored progress or licensed teacher PDFs,
  introduce server-verified authentication and appropriate consent/permissions first.
- Do not put a shared password in browser JavaScript; that is not security.

CONTENT
Questions are original short exercises based on the 2023 WCED Grade 11 Life Sciences
revision resources uploaded for the CCC pilot. Verify against current curriculum and
Franka's school exam requirements before a wider release.
